description: Show the next-session menu from docs/next-sessions.md and start the one picked
---

Grep `docs/next-sessions.md` for `^## Session: ` and reply with the headings as a numbered list (names only, one line each, in file order). Then a "Later ideas" line and the headings from `docs/someday-sessions.md`, numbered on from the first list. Then give a markdown link to `docs/next-sessions.md`, and recommend one entry. The list is a ranked backlog, so recommend the first entry unless its heading names a blocker, in which case recommend the first unblocked one. One sentence, taken from that entry's Goal, saying why it is next. Then ask which to start. If an argument was given ($ARGUMENTS), treat it as the pick (a number or a name) and skip the list, the link and the recommendation.

When one is picked: first rename this session to the entry's heading, so parallel sessions stay distinguishable. The owner asked for this rename. In Cursor, call `rename_chat` on `cursor-app-control` with that heading (discover the schema, then call it). In the desktop app, call `mcp__ccd_session_mgmt__set_session_title`, loaded with ToolSearch if deferred. Use whichever of those tools exists. Then read only that entry, in whichever of the two files has it (Read with offset and limit), read its "Reads first" docs, set its "Last touched" date to today, and carry out its starting prompt as if the owner had typed it.
